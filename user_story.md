# User Story

## Title

Todo Task Management

## User Story

As a Todo List user, I want to create, view, complete, and delete tasks so that I can keep track of my work.

## Scope

The application is a simple Todo List.

The initial scope includes:

- Creating tasks
- Viewing tasks
- Completing tasks
- Reopening completed tasks
- Deleting tasks

The application should remain intentionally simple. The purpose of the project is to demonstrate an agentic software development lifecycle using Claude capabilities rather than to build a feature-rich Todo application.
